# screenshot-notebook

An app to make screenshots and have a growing list of the new screenshots you made.

## List of current features:

1. Take screenshot of screen which adds the the list of screenshots made.
2. The screenshots made in the session can be seen in each tab window.
3. Can copy and save the screenshot made.

## Current list of features to be added:

1. Buttons for both snipping screenshots and full screenshots of current screen.
2. Snipping tool will have a press and drag functionality freezing the screen so user can selection portion of the screen to take screenshot of.
